# Тема 1-2. Основи аналізу та алгоритмічні стратегії

## Завдання 1. Мінімум і максимум

Функція `find_min_max(numbers)` рекурсивно ділить масив на дві частини, знаходить мінімум і максимум у кожній частині та об'єднує результати.

Особливості реалізації:

- повертає кортеж `(minimum, maximum)`;
- використовує рекурсивний підхід;
- має часову складність `O(n)`;
- для порожнього списку викликає `ValueError`.

Запуск:

```bash
python task_1.py
```

## Завдання 2. Черга 3D-принтера

Функція `optimize_printing(print_jobs, constraints)` перетворює вхідні словники на dataclass-структури, сортує завдання за пріоритетом і жадібно формує групи для одночасного друку.

Правила:

- пріоритет `1` друкується раніше за `2`, а `2` раніше за `3`;
- порядок завдань з однаковим пріоритетом зберігається;
- група не перевищує `max_volume` та `max_items`;
- час друку групи дорівнює максимальному `print_time` серед моделей у групі;
- загальний час дорівнює сумі часів усіх груп.

Часова складність: `O(n log n)` через сортування завдань за пріоритетом.

Запуск:

```bash
python task_2.py
```

Очікуваний результат:

```text
Тест 1 (однаковий пріоритет):
Порядок друку: ['M1', 'M2', 'M3']
Загальний час: 270 хвилин

Тест 2 (різні пріоритети):
Порядок друку: ['M2', 'M1', 'M3']
Загальний час: 270 хвилин

Тест 3 (перевищення обмежень):
Порядок друку: ['M1', 'M2', 'M3']
Загальний час: 450 хвилин
```
